# DownArt

个人使用的移动端工具 App，用于抓取、下载并管理主流内容平台上的公开内容。

- 技术栈：Expo（React Native），跨端 iOS / Android
- v0.0.1 计划支持：Twitter（X）、Instagram 的图片与视频
- 状态：**规划中**，v0.0.1 的需求与设计见 [`docs/v0.0.1/`](docs/v0.0.1/)
- 分发方式：iOS 暂不发布；Android 通过 GitHub Release
- 应用标识：`nbspace.downart.ios` / `nbspace.downart.android`
